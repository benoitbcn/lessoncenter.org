# LessonCenter — Site vitrine (Cloudflare Pages)
- **Build command** : `npm run build`
- **Output directory** : `dist`
- **NODE_VERSION** : `20` (Text)

Le script de build copie simplement `/site` vers `/dist`.

## Pages
- `/` (index) — Hero, programmes, témoignages, FAQ, CTA
- `/about.html`, `/programmes.html`, `/pricing.html`, `/faq.html`, `/contact.html`
- `robots.txt`, `sitemap.xml`, `404.html`

## Personnalisation
- Logos : `assets/img/logo.svg` et `assets/img/favicon.svg`
- Styles : `assets/css/style.css`
- JS léger : `assets/js/main.js`
